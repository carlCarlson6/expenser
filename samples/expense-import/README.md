# Expense import — live test files

Sample files for manually testing **Expenses → Import** (`npm run dev`).
They assume the default Spanish categories (Supermercado, Restaurantes, Transporte,
Vivienda, Suministros, Ocio, Salud, Compras, Viajes, Otros). On an English profile
the same files simply exercise "categories to create" instead.

To use: open **Expenses → Import**, drag a file in, check the preview, then import.
Everything below was verified against the real pipeline (parsers + validation).

## Suggested test order

### 1. Happy paths

| File | Tests | Expected |
|---|---|---|
| `01-happy-en.csv` | English headers, ISO dates, dot decimals | Auto-mapping; 4 valid rows; panel lists **Streaming** as a new category |
| `02-happy-es.csv` | UTF-8 BOM, `;` delimiter, `1.234,56` amounts, accents, quoted fields | Auto-mapping; 4 valid rows; `salud` matches existing **Salud** |
| `xlsx/01-happy.xlsx` | Real Excel date cells, numeric amounts | Auto-mapping; 3 valid rows, dates keep their day; **Café** is new |

### 2. Categories

| File | Tests | Expected |
|---|---|---|
| `07-new-categories.csv` | New names + spelling variants + case/accent matches | 7 valid; panel shows only **Mascotas (2)** and **Café (2)**; SUPERMERCADO / restaurantes / Transporte match existing |
| `06-empty-and-other-category.csv` | Blank and spaces-only category cells | 3 valid; rows show "Uses Otros"; nothing new created |

### 3. Duplicates

| File | Tests | Expected |
|---|---|---|
| `08-duplicates.csv` | Duplicate warning | Import it **once** (3 expenses), then import the **same file again**: 3 amber rows + "Exclude duplicates" button |

### 4. Column mapping

| File | Tests | Expected |
|---|---|---|
| `03-no-header.csv` | No header row | Header toggle starts **off**; nothing mapped; map Fecha/Importe/Categoría/Concepto manually |
| `04-unknown-headers.csv` | Unrecognized headers (`Col1…`) | Nothing detected; tick **"First row is a header"**, then map the four columns |

### 5. Errors

| File | Tests | Expected |
|---|---|---|
| `05-mixed-errors.csv` | Every row error type | 9 rows: **2 valid / 7 invalid** (bad date, non-numeric, zero, 205-char description, 55-char category, empty date, empty amount); submit blocked |
| `xlsx/02-errors-and-text.xlsx` | Mixed cell types + second sheet | 5 rows from the first sheet only: **2 valid / 3 invalid**; text dates/amounts parse; sheet "Hoja2" is ignored |

### 6. Dates

| File | Tests | Expected |
|---|---|---|
| `10-date-formats.csv` | ISO, `DD/MM/AAAA`, `DD-MM-AAAA`, dots, time suffix, ambiguity | 10 rows: **9 valid / 1 invalid** (`31/02/2026`). Row `03/04/2026` becomes 2026-04-03 with "day-first" on, 2026-03-04 with it off |

### 7. Amounts, quoting, blank lines

| File | Tests | Expected |
|---|---|---|
| `09-signed-amounts.csv` | `-12,34`, `(8,50)`, `€ 15,99`, `EUR 1.234,56`, `+7,25`, `12,34-` | All 6 valid, all positive |
| `11-quoted-fields.csv` | Commas, semicolons, escaped quotes, newline inside a field | 4 valid; descriptions keep their exact text |
| `12-blank-rows.csv` | Blank lines between and after rows | 3 rows only |

### 8. Scale and hard limits

| File | Tests | Expected |
|---|---|---|
| `13-large-5000.csv` | Big import, pagination, duplicate check | 5000 valid rows, 50 pages; import finishes in one atomic call |
| `14-too-many-10001.csv` | Row cap | Rejected immediately: "Too many rows… (max 10000)" |
| `15-header-only.csv` | Header but no data | Loads with 0 rows; footer says the file has no rows |
| `16-empty.csv` | 0 bytes | "The file has no rows" |
| `17-corrupt.xlsx` | Renamed text file | "Could not read this file…" |
| `18-legacy.xls` | Legacy Excel | "Unsupported file type. Use CSV or .xlsx." |

## Notes

- These samples write real expenses into the profile you are signed into. Use
  `08-duplicates.csv` last if you want to see the duplicate flow, or delete the
  imported rows from the table afterwards.
- `.xlsx` files were generated by hand (zip + XML); `xlsx/02` also contains a
  decoy second sheet to confirm only the first sheet is read.
